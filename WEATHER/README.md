# 🌦️ Weather Forecast Website

## 📌 Project Overview
- Interactive weather dashboard to view city-wise weather reports
- Allows users to search and select any city
- Displays real-time and forecasted weather data in a clean UI
- Focuses on clarity, visualization, and usability

---

## 🛠️ Tech Stack
- HTML  
- CSS  
- JavaScript  
- Canvas (used for temperature graph visualization)

---

## ✨ Features
- City search and selection
- Current temperature and weather condition display
- Hourly temperature forecast shown in graph format
- Wind speed information
- Humidity level indicator
- Precipitation details
- Chance of rain percentage
- UV index status
- “Feels like” temperature display
- Weekly weather forecast with temperature and rain chances
- Time-based weather tracking

---

## 📊 Data Visualization
- Hourly temperature graph rendered using **HTML Canvas**
- Visual comparison of temperature changes throughout the day
- Clear and readable chart layout

---

## 🎨 UI & Design
- Modern dashboard-style layout
- Weather data displayed using cards and icons
- Clean, dark-themed interface
- Easy-to-read and user-friendly design

---

## 🔮 Future Enhancements
- Live weather API integration
- Auto-detect user location
- Dark and light mode toggle
- Fully responsive mobile design
- Weather alerts and notifications
